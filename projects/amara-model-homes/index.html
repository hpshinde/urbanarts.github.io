Amara Model Homes

A model home must make an unbuilt life legible. These interiors use furniture, storage, light and circulation to help prospective residents understand each apartment beyond its plan.

Status
Completed
Urban Arts role
Design + build
Scope
Model-home interiors · Furniture · Styling · Turnkey implementation

Project note

Urban Arts designed and delivered a family of model homes for different apartment types. Each has its own colour and material identity, but the purpose remains consistent: to make dimensions, movement, storage and daily occupation immediately understandable rather than merely stage a photogenic interior.
